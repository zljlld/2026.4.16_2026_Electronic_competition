# 电子竞赛 - 智能三子棋对弈装置

## 📋 项目简介

本项目是基于 **STM32F103** 微控制器的智能三子棋（井字棋）自动对弈装置，能够根据上位机指令自动完成棋子的抓取、移动和放置操作。系统采用双轴步进电机驱动实现二维平面运动控制，配合电磁铁吸附机构和舵机升降机构，实现全自动化的棋子搬运功能。

### 核心特性

- ✅ **双轴精密运动控制**：X/Y轴独立控制，支持编码器闭环反馈
- ✅ **多模式操作**：手动调试、编码器控制、自动下棋等多种工作模式
- ✅ **视觉坐标转换**：支持K230视觉模块坐标到步进电机坐标的精确映射
- ✅ **限位保护**：四向硬件限位开关，防止超程损坏
- ✅ **OLED实时显示**：实时显示当前位置、角度和工作模式
- ✅ **串口通信**：与上位机/K230视觉模块进行数据交互
- ✅ **模块化设计**：清晰的代码结构，易于维护和扩展

## 🎯 功能说明

### 1. 工作模式

系统支持5种工作模式，通过编码器按键循环切换：

| 模式 | 名称 | 功能描述 |
|------|------|----------|
| **Mode 0** | 调整模式 | 手动测试X/Y轴电机和舵机，用于系统校准和调试 |
| **Mode 1** | X轴设置 | 通过旋转编码器控制X轴步进电机移动到指定位置 |
| **Mode 2** | Y轴设置 | 通过旋转编码器控制Y轴步进电机移动到指定位置 |
| **Mode 3** | 舵机调节 | 通过旋转编码器直接控制舵机角度（0~180°） |
| **Mode 4** | 自动下棋 | 接收串口指令，自动完成取子→移动→放子的完整流程 |

### 2. 自动下棋任务

系统支持多种下棋任务类型，通过串口接收指令格式为 `(task,coord1,coord2)` 或 `(task,coord1,cam_x,cam_y)`：

#### 题目1/2/4/5：棋盘内移动
- **指令格式**：`(task, start_cell, end_cell)`
- **示例**：`(1, 5, 12)` 表示从5号格拿起棋子放到12号格
- **坐标范围**：1~19（对应棋盘19个有效位置）

#### 题目3：待命区到视觉坐标
- **指令格式**：`(3, wait_cell, cam_x, cam_y)`
- **示例**：`(3, 2, 135, 63)` 表示从2号待命区拿子，放到K230视觉坐标(135,63)
- **待命区**：1~10号格
- **视觉坐标**：K230相机坐标系，自动转换为步进电机坐标

### 3. 棋盘布局

```
        右待命区 (Y[4])
    ┌─────┬─────┬─────┬─────┬─────┐
    │     │  1  │  2  │  3  │  4  │  5  │  ← X[0] 最上行
    ├─────┼─────┼─────┼─────┼─────┤
    │     │  6  │  7  │  8  │  9  │ 10  │  ← X[1]
    ├─────┼─────┼─────┼─────┼─────┤
    │     │ 11  │ 12  │ 13  │ 14  │ 15  │  ← X[2] 中心行
    ├─────┼─────┼─────┼─────┼─────┤
    │     │ 16  │ 17  │ 18  │ 19  │     │  ← X[3]
    ├─────┼─────┼─────┼─────┼─────┤
    │     │     │     │     │     │     │  ← X[4] 最下行
    └─────┴─────┴─────┴─────┴─────┘
   左待命区       博弈区(9格)      右待命区
   (Y[0])      (Y[1]~Y[3])      (Y[4])
```

**坐标编号规则**：
- **1~5号**：右待命区（从下到上）
- **6~10号**：左待命区（从下到上）
- **11~19号**：中间博弈区（从右到左、从下到上的3×3网格）

## 🛠️ 硬件架构

### 核心控制器
- **MCU**：STM32F103系列（ARM Cortex-M3内核）
- **主频**：72 MHz
- **Flash**：128 KB
- **RAM**：20 KB

### 运动控制系统

#### 步进电机驱动
- **驱动器型号**：TMC2209（静音步进电机驱动芯片）
- **电机数量**：2个（X轴 + Y轴）
- **控制方式**：脉冲+方向控制
- **细分设置**：1/4微步细分
- **编码器反馈**：TIM1编码器模式，实现位置闭环监测

#### 舵机控制
- **控制通道**：TIM4_CH3 PWM输出
- **频率**：50 Hz（周期20ms）
- **脉宽范围**：500μs ~ 2500μs（对应0°~180°）
- **中位角度**：90°（初始位置）
- **取放角度**：172°（下探抓取/放置棋子）

#### 电磁铁控制
- **控制引脚**：YA_S
- **功能**：吸附/释放金属棋子
- **工作状态**：高电平吸附，低电平释放

### 传感器系统

#### 限位开关
- **数量**：4个（X轴左右 + Y轴左右）
- **引脚配置**：
  - X轴左限位：PB10
  - X轴右限位：PB1
  - Y轴左限位：PB0
  - Y轴右限位：PA7
- **消抖处理**：软件消抖20ms，防止误触发
- **中断响应**：EXTI外部中断，实时检测限位状态

#### 旋转编码器
- **接口**：TIM1编码器模式
- **功能**：
  - Mode 0/3：直接控制舵机角度
  - Mode 1：控制X轴目标位置
  - Mode 2：控制Y轴目标位置
- **灵敏度**：每计数1步对应30个步进电机脉冲

### 人机交互

#### OLED显示屏
- **接口**：I2C（I2C1）
- **分辨率**：128×64像素
- **显示内容**：
  - X/Y轴当前步数值
  - 舵机当前角度
  - 历史最大步数值（用于标定）
  - 当前工作模式

#### 串口通信
- **接口**：USART2
- **波特率**：默认配置（可通过CubeMX修改）
- **协议**：ASCII文本格式，括号包裹坐标数据
- **功能**：接收上位机/K230指令，发送执行状态

### 定时器资源分配

| 定时器 | 功能 | 配置参数 |
|--------|------|----------|
| **TIM1** | 编码器输入捕获 | 双通道正交解码 |
| **TIM2** | 步进电机时基中断 | 预分频72，重装载值600（1kHz中断频率） |
| **TIM3** | STEP脉冲宽度控制 | 预分频72，重装载值20（20μs脉冲宽度） |
| **TIM4** | 舵机PWM输出 | 预分频72，重装载值20000（50Hz，1MHz计数时钟） |

### 核心模块说明

#### 1. 主控制循环（main.c）

#### 2. 自动下棋状态机（Mode4_AutoChess）

状态流转图：
```
State 0: 等待有效指令
    ↓
State 1: 移动到取子位置（coord1）
    ↓
State 2: 舵机下压到172°
    ↓
State 3: 电磁铁吸附 → 舵机抬回90°
    ↓
State 4: 移动到放子位置（coord2或视觉坐标）
    ↓
State 5: 舵机下压到172°
    ↓
State 6: 电磁铁释放 → 舵机抬回90°
    ↓
State 7: 移动到安全位置（避开相机视野）
    ↓
返回 State 0，切换至Mode 1
```

#### 3. 坐标转换系统

**K230视觉坐标 → 步进电机坐标**

```c
void CameraCoord_ToStep(int16_t cam_x, int16_t cam_y, 
                        int32_t *x_step, int32_t *y_step)
{
    // K230坐标系：向上为Y正方向，向左为X正方向
    // 我方步进坐标系：向上为X正方向，向右为Y正方向
    
    int32_t delta_cam_x = cam_x - K230_CENTER_X;  // 134
    int32_t delta_cam_y = cam_y - K230_CENTER_Y;  // 76
    
    *x_step = board_x_step[2] + (delta_cam_y * STEP_GRID_DELTA) / K230_GRID_DELTA;
    *y_step = board_y_step[2] - (delta_cam_x * STEP_GRID_DELTA) / K230_GRID_DELTA;
}
```

**关键参数**：
- `K230_CENTER_X/Y`：K230坐标系中心点(134, 76)
- `K230_GRID_DELTA`：K230相邻棋格坐标差25像素
- `STEP_GRID_DELTA`：步进电机相邻棋格步数差1130步
- `board_x_step[2]/board_y_step[2]`：棋盘中心格对应的步数值

## 🎮 使用说明

### 上电初始化

1. 连接电源（确保电压正确）
2. 连接ST-Link烧录器（如需更新固件）
3. 连接串口助手到USART2（用于接收指令）
4. 上电后系统自动执行以下操作：
   - 初始化GPIO、定时器、串口、I2C
   - 启动编码器读取
   - 启动TIM2中断（步进调度）
   - 启动舵机PWM输出
   - 启动串口接收中断
   - OLED显示初始界面

### 模式切换

**操作方法**：按下编码器按键（Encoder_KEY）

```
Mode 0 → Mode 1 → Mode 2 → Mode 3 → Mode 4 → Mode 1 → ...
（循环切换，不回到Mode 0）
```

### Mode 0：调整模式

**用途**：系统校准和手动测试

**操作流程**：
1. 上电后默认进入此模式（或从其他模式切换回来）
2. 触碰限位开关会自动反向运动
3. OLED显示：
   ```
   Xcount: 当前X轴步数
   Ycount: 当前Y轴步数
   servo: 当前舵机角度
   X_MAX: X轴历史最大步数
   Y_MAX: Y轴历史最大步数
   MODS: 0
   ```
4. 旋转编码器可直接控制舵机角度
5. 记录X_MAX和Y_MAX用于后续坐标标定

### Mode 1/2：编码器控制轴运动

**用途**：精确定位到指定位置

**操作流程**：
1. 切换到Mode 1（X轴）或Mode 2（Y轴）
2. 旋转编码器，电机按增量移动
3. 灵敏度：每计数1步对应30个步进脉冲
4. OLED显示当前X/Y轴步数值
5. 到达限位自动停止

### Mode 3：舵机调节

**用途**：单独测试舵机动作

**操作流程**：
1. 切换到Mode 3
2. 旋转编码器控制舵机角度（0°~180°）
3. 步进电机不动作
4. OLED显示当前舵机角度

### Mode 4：自动下棋

**用途**：执行完整的取子→移动→放子流程

**指令格式**：

```
题目1/2/4/5: (task, start_cell, end_cell)
题目3:       (task, wait_cell, cam_x, cam_y)
```

**示例**：

```bash
# 从5号格拿子放到12号格
(1,5,12)

# 从2号待命区拿子，放到K230视觉坐标(135,63)
(3,2,135,63)

# 从8号格拿子放到15号格
(2,8,15)
```

**执行流程**：
1. 收到指令后自动切换到Mode 4
2. 移动到取子位置
3. 舵机下压→电磁铁吸附→舵机抬起
4. 移动到放子位置
5. 舵机下压→电磁铁释放→舵机抬起
6. 移动到安全位置（300, 300）
7. 串口回复"OK"
8. 自动切换回Mode 1

**注意事项**：
- 确保起始位置在棋盘范围内
- 题目3的视觉坐标需在允许范围内：
  - X: 1362 ~ 6122步
  - Y: 2751 ~ 9299步
- 执行过程中不要手动干预电机运动

## 🔍 调试技巧

### 1. 坐标标定

**目的**：确定每个棋格对应的步进电机坐标值

**步骤**：
1. 进入Mode 0（调整模式）
2. 手动移动机械臂到棋盘左上角（1号格附近）
3. 记录此时的Xcount和Ycount值
4. 依次移动到各个棋格，记录坐标
5. 更新`board_x_step[]`和`board_y_step[]`数组

**提示**：
- X_MAX和Y_MAX会在触碰右限位时自动保存
- 可用于估算行程范围

### 2. 舵机角度校准

**目的**：确保舵机90°对应水平位置，172°对应垂直下探

**步骤**：
1. 进入Mode 3（舵机调节）
2. 旋转编码器找到机械臂水平位置
3. 记录此时OLED显示的角度值
4. 如需修正，修改`SERVO_PULSE_INIT_US`宏定义
5. 同样方法校准172°取放位置

### 3. 限位开关测试

**目的**：验证限位开关是否正常工作

**步骤**：
1. 进入Mode 0
2. 手动触发各个限位开关
3. 观察电机是否立即反向
4. 检查OLED显示的计数值是否正确清零

### 4. 串口通信测试

**工具**：串口助手（如PuTTY、SecureCRT、SSCOM）

**步骤**：
1. 打开串口，设置正确波特率
2. 发送测试指令：`(1,5,12)`
3. 观察系统是否执行相应动作
4. 执行完成后应收到"OK"回复

**常见问题**：
- 无响应：检查串口接线和波特率
- 指令解析失败：确认格式为英文括号和逗号
- 坐标超出范围：检查坐标值是否在1~19之间

### 5. 编码器灵敏度调整

**位置**：`Mode1_X_ByEncoder()`和`Mode2_Y_ByEncoder()`函数

```
// 当前灵敏度：每计数1步对应30个步进脉冲
target = (int32_t)X_tim2_tick_count + (int32_t)delta * 30;

// 如需更精细控制，减小系数（如改为10）
// 如需更快移动，增大系数（如改为50）
```

## ⚠️ 注意事项

### 安全警告

1. **电源极性**：务必确认电源正负极正确，反接可能烧毁电路
2. **电压匹配**：步进电机、舵机、电磁铁的供电电压需符合规格
3. **机械限位**：虽然有限位开关，但避免频繁撞击限位
4. **急停措施**：建议增加物理急停按钮，异常时切断电源

### 使用建议

1. **首次上电**：
   - 先断开电机电源，仅给控制板上电
   - 检查OLED是否正常显示
   - 测试按键和编码器是否响应
   - 确认无误后再连接电机电源

2. **运动测试**：
   - 先在Mode 0下低速测试各轴运动
   - 确认限位开关工作正常
   - 逐步增加移动距离

3. **自动下棋前**：
   - 确保机械臂在安全起始位置
   - 确认棋盘上棋子摆放正确
   - 检查电磁铁吸附力是否足够

4. **长期运行**：
   - 定期检查螺丝是否松动
   - 清理导轨和丝杆上的灰尘
   - 监测电机温度，避免过热

### 常见故障排查

| 故障现象 | 可能原因 | 解决方法 |
|---------|---------|---------|
| OLED无显示 | I2C接线错误/地址不对 | 检查SDA/SCL接线，确认OLED地址 |
| 电机不转 | 使能引脚未拉低/驱动器故障 | 检查EN引脚电平，测量驱动器输出 |
| 限位无效 | GPIO未配置中断/接线松动 | 检查EXTI配置，紧固接线 |
| 编码器无响应 | TIM1未启动编码器模式 | 检查`HAL_TIM_Encoder_Start()`调用 |
| 舵机抖动 | PWM频率不对/电源不稳 | 确认TIM4配置为50Hz，增加滤波电容 |
| 串口无数据 | 波特率不匹配/接线错误 | 核对波特率，检查TX/RX交叉接线 |
| 坐标不准确 | 标定值偏差/累积误差 | 重新标定棋盘坐标，检查机械间隙 |
